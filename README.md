# Arduino Projects

This repository contains a collection of hands-on Arduino and C++ projects completed as part of independent technical practice. These projects provided experience with microcontroller programming, electronic components, sensors, actuators, and basic embedded-system concepts.

## Projects

### Spaceship Interface

An interactive control-panel project using Arduino inputs and LEDs to simulate a spaceship interface. This project introduced digital input/output, conditional logic, and basic circuit construction.

[View Spaceship Interface Project](spaceship-interface)

### Temperature Sensor

An Arduino-based temperature monitoring project using a temperature sensor and LED indicators. This project provided practice reading analog sensor data, converting measurements, and using program logic to control outputs based on environmental conditions.

[View Temperature Sensor Project](temperature-sensor)

### Color Mixing Lamp

An interactive lighting project using Arduino and an RGB LED to generate different colors based on sensor input. This project provided experience with analog inputs, pulse-width modulation (PWM), RGB color control, and mapping sensor readings to output values.

[View Color Mixing Lamp Project](color-lamp)

### Servo Motor

An Arduino project using a servo motor and input controls to manipulate motor position. This project provided experience controlling an actuator, working with Arduino libraries, and translating input values into physical movement.

[View Servo Motor Project](servo-motor)
